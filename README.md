Перед запуском бота из репозитория:

1) перейти в https://my.telegram.org/auth и получить USER_API_ID и USER_API_HASH для вашего тг аккаунта (не рекомендуется использовать основной свой аккаунт, т.к. есть небольшой риск блокировки из-за подозрительной активности пользователя).

2) открыть @BotFather в тг и получить BOT_TOKEN для вашего бота, который в дальнейшем будет отправлять в чат уведомления и создайте для него команды доступные из личного чата: start, stop_continue_target, settings, add_target, remove_target, help, clear_data и команда, доступная из групп: link_group.

3) Восстановить базу данных из файла ./db/backups/backups_db.bak

4) создать файл ini.env, в котором указать:
API_ID="ваш USER_API_ID"
API_HASH="ваш USER_API_HASH"
BOT_TOKEN="ваш BOT_TOKEN"
USER_SESSION_NAME = "имя сессии вашего пользователя в тг"
TARGET_IDS = "id чатов целей из которых берутся сообщения, разделитель:_"

DRIVER="Драйвер для подключения к MS SQL Server"
SERVER="имя сервера"
DATABASE="имя БД"
USERNAME="имя пользователя БД"
PASSWORD="пароль пользователя БД"

5) Запустить бота, войти в аккаунт тг через консоль (по логину и паролю того аккаунта, для которого получали API_ID и API_HASH).

6) Использовать бота.
